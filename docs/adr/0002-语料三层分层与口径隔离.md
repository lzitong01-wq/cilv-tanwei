# 语料三层分层，口径互不混算

语料分为 Tier 0（题库 1000 题）、Tier 1（官方 API 423 篇，唯一基准口径）、Tier 2a（与 Tier 1 同源的公开整理本，可复用其自带标注）、Tier 2b（非同源公开语料，声律为本地计算口径）。基准解题只允许 Tier 1；Tier 2 唯一进入解题的例外是三层兜底，且答案须显式警示"非官方口径"。

## 为什么

实测证明同源程度决定口径可用性：官方 200 篇清词与 poetry-source 清词库**正文逐字一致（200/200）**，其自带拼音在可对齐句上与官方标注一致率 94.15%，高于 pypinyin 首读的 91.57%；而官方 203 篇宋词与同库宋词**并非同一版本**（唯一定位 163/203、逐字一致 104/163），同库拼音一致率反而低于 pypinyin（91.81% vs 93.14%）。把两者统称"Tier 2 公开语料·本地计算"会掩盖这一差别，并让 Tier 2a 的同源红利被误当作泛化能力。

## 备选与否决原因

- **单一 Tier 2 层**：否决——口径不同、覆盖不同、授权不同。
- **只用 Tier 1（423 篇）**：否决——检索、图谱、词人画像需要样本量，423 篇内多数词人只有一两首，画像立不住。
- **把 Tier 2a 直接当官方口径**：否决——同源只保证文本一致，声律仍有 5.85% 残差，必须差集修正并标注。

## 后果

- 每个结果都必须带层级来源标签；混算即污染基准。
- 指标必须拆成同源作品／非同源作品／库外兜底三档披露（见总体规划 §13 同源自证污染风险）。

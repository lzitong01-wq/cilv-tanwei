# 情感评估基准由 AI 标注生成

人力标注不可得，因此情感评估所需的参考集合由模型按成文规范生成，称为 **AI 标注基准集**（AI-labeled reference set）。它**不是人工金标，也不是官方标注**；对外一律按此称呼，不得简称为"金标"。评估结果表述为"与 AI 标注基准集的一致率"，不表述为"情感识别准确率"。

## 为什么

榜题要求提供可溯源的声情能力，但官方当前不提供情感标注，赛题也未提供人工标注资源。若因此完全不做情感评估，则该板块既无验收依据、也无复现可能；若把模型标注当作金标，则会把模型自身的偏好包装成客观真值——比不做更危险。

折中做法是：把"标注"变成可审计的工程过程——规范成文、抽样分层、多次独立标注、分歧仲裁、一致性统计、版本冻结——并把它的局限显式写进所有相关产出。

## 怎么防止自证污染

1. **留盲测子集**：抽样中约 20% 不参与标注，只用于评估，标注规范不得针对盲测集调整；
2. **报告两个数**：与基准集的一致率，以及基准集自身的标注者间一致性（衡量基准集质量）；
3. **不做训练**：不得用该基准集微调后再在同一集合上报告成绩；
4. **口径披露**：任何界面与报告都标注"由模型标注、未经人工核验"。

## 后果

- 板块 G 可从"只有候选"升级到"有可复现的评估口径"，但结论强度受限；
- ADR-0005 的边界结论不变（仍不做情感识别与打标承诺、不推断作者生平），本 ADR 补充的是**评估基准的来源与披露方式**；
- 若日后有少量人工抽检资源，应优先用于抽检该基准集，而非重做整套标注。

# 不做情感识别与打标，只提供情感候选

产品不产出情感判定结论，不给作品打情感标签，也不承诺任何情感识别准确率。只提供形式线索（仄声比例、句末韵部、长句率、题材词频）与文本作为依据，由模型生成候选情感方向，并一律标注"未验证"、说明不能推出作者生平与具体事件。

## 为什么

三层原因同时成立：官方当前不提供情感标注（API 的史证接口当时为空）；V5 临界题（C5）官方明确说明景物/感受语义**不是经验证金标准**；研究资产《最小领域理解》指出"声情不等于简单情感标签"——形式、词调与音乐传统、文献理论、具体表达之间存在解释环节，"形式相近，不自动证明情绪相同"。在没有标注真值与理论桥梁的情况下声称情感识别能力，是不可核验的承诺。

## 备选与否决原因

- **做情感分类并给准确率**：否决——无金标，无法验证。
- **用模型自由生成情感结论**：否决——正是把不可验证的推断包装成结论。
- **完全不做情感相关输出**：否决——C5 与声情问答确有此需求，候选形式可满足研究需要。

## 后果

- 情感相关输出的默认标签是"未验证"，且必须带边界说明。
- 复赛条件明确：官方发布情感标注或史证接口后，再升级为带金标的情感分析并新增评测，届时另立 ADR 取代本条。
- C5 的硬门禁是代理字段（引文可定位、数值、方向、边界），不是语义正确率。

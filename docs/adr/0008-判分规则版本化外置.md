# ADR-0008：判分规则版本化外置（可热修）

日期：2026-11-04
状态：已采纳并实现（`app/backend/rules.json` + `core/rules.py`）

## 背景

V6.1 §1.7 的工程推论：评测集与训练集**同构但换作品、换措辞**，判分规则必须能
在不改引擎代码的前提下调整（题面措辞漂移由外置配置吸收）。答辩 Q5 的口径也依赖这一点。

此前判类关键词、C5 边界文本、越界词表、模型配置全部硬编码在 `engine.py` / `sidecar.py`，
评测集措辞一变就要发版，无法兑现"规则可热修"的承诺。

## 决策

把以下内容外置到 `app/backend/rules.json`（单一来源，带版本号）：

| 项 | 内容 |
|---|---|
| `categories` | 五类的名称与判类关键词（按顺序匹配） |
| `formulas` | 分段、比例、阈值、变化值、平仄映射、引文策略、未知处理口径 |
| `c5` | C5 边界与状态声明（必须与金标逐字一致） |
| `boundary_claims` | 越界闸门价值判断词表 |
| `model_profiles` | 两个模型的 token 预算、超时、思考开关 |

`core/rules.py` 负责加载与校验：**缺字段在 import 阶段抛错，不静默回退到内置默认值**——
否则会误以为外置生效、实际仍跑旧规则。`GET /api/rules` 暴露当前生效版本。

## 后果

- 措辞漂移时改 JSON 即生效（重启进程）；`tests/test_rules.py` 含"模拟热修关键词立即生效"用例。
- C5 边界文本与金标逐字一致的约束由测试钉死（`test_c5_text_matches_gold_verbatim`）。
- 公式本体（舍入、分段计算）仍在引擎代码中：JSON 登记口径与常量，公式实现变更需走测试回归，
  防止"改个 JSON 就把算式改坏"。
- 遵守既有红线：禁止题号特判与逐题打补丁（V6.1 §1.7），rules.json 只承载**类别级**规则。

# 模型只出候选，不参与声律事实

模型的职责边界定为：只消费引擎产出的「事实卡」，只产出「候选解读」，不产出、不修改任何声律数值与判定口径（平仄、入声、句数、比例、变幅、排序、极差、阈值选句）。事实卡的每个数字都有可回跳的出处；模型输出必须通过结构、事实、越界、标注四道闸门后才允许进入界面，未通过者一律不展示。

## 为什么

双模型实测（12 次调用）表明两个模型都会产生事实错误：qwen 曾把七字「谁念西风独自凉」的入声标记全部标真，flash 曾把 4 平 3 仄的句子说成"仄声居多"。把声律事实交给模型，等于把评测可信度交给一个概率组件。

## 备选与否决原因

- **让模型直接产出整段答案**：否决——无法复算、无法回归、无法定位错误来源。
- **让模型只产出数值**：否决——同类错误照样发生，且更难发现。
- **允许模型参与选句或排序**：否决——题库基准依赖确定性规则，一旦掺入概率成分，1000 题的字段通过率将失去意义。

## 后果

- 模型的职责被压缩为"把已确定的事实写成研究者可读的句子"，价值下降但可信度上升。
- 需要为此建事实卡、四道闸门与负向对照用例三件套工程（见总体规划 §6.4）。
- 一切声律相关结论的责任归属清晰：引擎负责正确，模型负责可读。

## 1. 结论摘要

题库"参考资料"字段不是客套标注，而是**官方语料来源的公开声明**。实测表明：

1. 官方 423 篇清词与 poetry-source 清词库**正文逐字完全一致（200/200）**——清词快照就是该公开整理本的公开镜像；
2. poetry-source 的清词与宋词分片**自带带调拼音**（`*.pinyin.json`），可作为 Tier 2 的现成字音来源；
3. 但"同源"**按朝代分化**：清词同源、宋词不同版本、元曲无拼音库。三者不能合并成一句"Tier 2 = 5–6 万首本地计算"；
4. 复用同源拼音在清词上确实优于 pypinyin（94.15% vs 91.57%），在宋词上反而略低（91.81% vs 93.14%）；
5. 库内拼音存在系统性漏标，必须与 pypinyin 合并使用，不能单用。

---

## 2. 三个库的实际结构（实测）

| 库 | 目录结构 | 规模 | 自带拼音 | 备注 |
|---|---|---|---|---|
| poetry-source | `source/词/{朝代}/ci.朝代.NNNN.{base,json,pinyin}.json` | 清 27 片（26,742 首）、宋 17 片（16,449 首），另有曲/诗/明/金/唐/五代/南北朝/隋/其他 | **清、宋均有 `*.pinyin.json`**（带调字母，逐句音节流） | `*.json` 只含正文；拼音在独立 `*.pinyin.json` |
| chinese-poetry | `宋词/ci.song.N.json` 分片 + `宋词/ci.db`（SQLite）；`元曲/yuanqu.json`；`纳兰性德/` | 宋词 22 片（约 21,000 首） | **无拼音**，字段仅 `author/paragraphs/rhythmic` | `paragraphs` 为逐句拆分，与官方句粒度高度一致 |
| chinese_word_rhyme | `Ci_Tunes.json` 等 | 818 词牌 | 韵书字表（古音） | 与本题无关，用于古音展示 |

粒度差异：poetry-source 的 `content` 按上下阕分项，但**其 `pinyin` 串内部按句号切分即为句号级音节流**，与官方 `prosody.lines` 的切法一致，可直接按句号对齐。

## 3. 清词：完全同源，库内拼音可用

| 指标 | 实测 |
|---|---|
| 官方清词作品 | 200 |
| 在 poetry-source 中唯一定位 | **200/200** |
| 正文逐字完全一致 | **200/200** |
| 句数与官方 `prosody.lines` 一致 | 200/200 |
| 库内拼音音节数 = 官方字数（可对齐句） | 581/1509（其余 928 句为库内漏标） |
| 库内拼音与官方逐句平仄一致（对齐句） | **547/581 = 94.15%** |
| pypinyin 首读同一批句一致 | 532/581 = 91.57% |
| 二者互补（任一命中） | **552/581 = 95.01%** |
| 两者都不一致 | 29 句（5.0%） |
| 库内拼音漏标 | 928 句、合计缺 1,244 字（636 句缺 1 字、270 句缺 2 字） |

结论：清词层面库内自带拼音**确实做过上下文处理**（优于 pypinyin 首读 2.58 个百分点），但必须用 pypinyin 补漏标，两者互补比单用任何一方都高。

## 4. 宋词：不同版本，库内拼音不占优

| 指标 | 实测 |
|---|---|
| 官方宋词作品 | 203 |
| 在 poetry-source 宋词库唯一定位 | 163/203（40 篇未唯一命中） |
| 正文逐字完全一致 | **104/163**（59 篇文本不同） |
| 句数与官方一致 | 136/163（27 篇粒度不同） |
| 拼音长度差出现负值 | 是（-1 至 -13），说明库内文本与官方文本并非同一版本 |
| 库内拼音一致（对齐句） | 415/452 = **91.81%** |
| pypinyin 首读同一批句 | 421/452 = **93.14%** |
| 二者互补 | 434/452 = **96.02%** |

结论：官方宋词快照**不是** poetry-source 宋词库的同一版本（更可能出自《全宋词》另一整理本）。宋词部分库内拼音略低于 pypinyin，Tier 2 对宋词只能定位文本，声律仍需本地计算。

## 5. 元曲

chinese-poetry 元曲仅 `yuanqu.json` 一个文件，未见拼音分片；官方元曲仅 20 篇，且包含 `(生上)` 等角色标记（work_id 26141 一篇正文按标点分 11 句、API 按分号分 12 句）。元曲必须走自建解析 + 明确的多音字/轻声未知项处理。

## 7. 新增风险：同源自证污染

官方快照与公开整理本同源，意味着：

- 在这些作品上取得的一致率，**包含"同源镜像"带来的红利**，不能等同于对未见作品的泛化能力；
- 若隐藏测试集取自同源清词，我们的一致率会偏高；若取自非清词或改写文本，则会回落；
- 因此报告必须把指标拆成三档并分别披露：**同源作品一致率 / 非同源作品一致率 / 库外作品（兜底路径）命中率**；
- 建议在产品里对 Tier 2a 结果加"与公开整理本同源"的来源标签，与 Tier 1 官方标注并列展示，不混算。

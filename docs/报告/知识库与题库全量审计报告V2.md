## 2. 唯一分句异常及其金标含义

423 篇中仅 1 篇出现“正文按。！？”分句数与 API 声律句数不一致：

- work_id：`26141`
- 作品：元·高明《蔡伯喈琵琶记》《清平乐》
- 正文按句号/问号/感叹号：11 句
- API `prosody.lines`：12 句
- 原因：第 5 句以分号“；”结尾，API 将其作为独立句。

用该篇所在的 `T-010-V2C4` 核对：

| 计算口径 | 后段平仄 | 后段仄声比例 | 金标 |
|---|---|---:|---:|
| API `split_after_line=6` | 平42、仄32 | **43.2%** | **43.2%** |
| 按标点自行分为 11 句、split=5 | 平48、仄36 | 42.9% | 不符 |

结论：**题库复算必须直接使用冻结 API 的 `prosody.lines` 与 `split_after_line`，不得对题库作品重新按标点分句。** 任意用户文本的解析是另一条独立链路，不能与基准解题共用未经验证的分句假设。

这一结果需要两个解析修正：

1. 题名可能嵌套书名号，例如：
   `吴文柔《谒金门·寄汉槎兄塞外见《今词初集》、《瑶华集》、《词综》、《词雅》》`

   `高明《蔡伯喈琵琶记》`、`柯丹邱《荆钗记》`。
   若只接受作者严格等于“高明”，14 个元曲 C4 锚点会产生假阴性。

修正后的检索规则是：首句定位 + 词牌过滤 + 作者“等于或为作者《剧作名》”匹配。题库锚点风险低，但不能用“搜索首句取第一条”代替唯一性校验。

## 4. 金标模板并非五套固定文本

将数字替换为 `<N>`、引号内候选替换为 `<Q>` 后，公开 140 题/类的归一化模板数如下：

| 类别 | 模板数 | 最大同模板组 |
|---|---:|---:|
| C1 | 36 | 27 |
| C2 | 12 | 25 |
| C3 | 53 | 15 |
| C4 | 7 | 75 |
| C5 | 8 | 42 |

因此，“从 700 条金标抽取五套模板后即可 ≥99% 精确匹配”的说法不成立。可做的是：

- 为每一类定义字段槽位；
- 归纳有限的句式分支（最长句单句/并列、比较方向、等比例、候选位置等）；
- 用统一渲染器生成答案；
- 在未见过的题上测整段精确匹配，而不是用同一批金标既拟合又验证。

C5 虽然有 8 种句式模板，但候选句内容随作品变化，且语义不是金标。整段匹配只能作为参考，不能替代代理评分。

## 5. C4 规则探针：公开 140 题

### 5.1 已确认规则

| 字段 | 规则 | 结果 |
|---|---|---:|
| 后段范围 | `line_no > split_after_line` | 140/140 |
| 各篇后段比例 | `ze/(ping+ze)×100`，保留一位小数 | 140/140 |
| 引文定位 | 金标引文必须是该篇后段某句的完整文本 | 140/140 |
| 极差 | 先取各篇一位小数展示值，再相减 | 140/140 |
| 排序 | 按展示比例降序；等比例时题面后出现的锚点在前 | 140/140 |

17/140 题存在一位小数等比例。采用“未舍入值排序”只能匹配 123/140，因此不能用未舍入值解释金标。实际规则是展示值排序加反向锚点次序。

全部选中字段（比例、排序、极差、引文）通过：**140/140**。C4 仍未完成的是整段文字逐字渲染与保密题验证，不是数值规则。

### 5.2 仍需全量验证

- C1、C2、C3 的 420 道公开普通题尚未逐字段全量回放；
- C5 的 140 道公开临界题尚未做代理字段全量回放；
- 保密 300 题未用于本轮规则调整；

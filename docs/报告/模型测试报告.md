## 2. 关键参数发现

| 发现 | 详情 |
|---|---|
| qwen3.8-27b 默认深度思考 | 交互延迟 **73.5s+**，3000 token 可能全被思考吃掉、正文为空（`finish_reason: length`） |
| **qwen 关思考开关** | `"chat_template_kwargs": {"enable_thinking": false}`，实测 **73.5s → 3.6s**，reasoning 归零，质量不降反稳 |
| step-3.7-flash 常驻思考 | 无需关闭（也关不掉），延迟 6.9–16.6s；**max_tokens ≤600 时正文为空**（思考吃光预算），须给足 1500+ |
| 计费口径 | flash 的 reasoning 不计入 `reasoning_tokens`（网关口径），延迟影响不大 |

## 3. 质量探针结果

| 探针 | step-3.7-flash | qwen3.8-27b（关思考） |
|---|---|---|
| 基础词学问答（浣溪沙格律） | 准确（需足量 token） | 准确，8.7s |
| 平仄+JSON（"谁念西风独自凉"，陷阱字"独"） | **全对**（独=仄+入声），JSON 合规，6.9s | **全对**，JSON 完美，3.6s |
| 高密度陷阱（"一生一代一双人"，三个"一"皆入声） | **平仄全对**，但 **pinyin 字段漂移**成中古拟音乱码（"bit"/"səŋ"），16.6s | **全对且拼音正常**（"yī"），4.5s |
| 声情阐释（同句声情分析） | **优**：准确点出下平七阳韵、入声"独"的顿挫效果，文采学理俱佳，9.1s | **事实性错误**：称"首句七字皆平"（实际"平仄平平仄仄平"），典型声律幻觉，6.3s |

## 4. 结论与架构影响

**① 双轨设计被实测强化。** LLM 声律判断"单点惊艳、规模不可靠"：flash 平仄判断连续全对但字段内容会漂移；qwen 关思考后在自由阐释中直接幻觉声律事实。→ **声律事实的唯一来源是确定性引擎**；LLM 输出必须 JSON 校验 + 字段级校验（如拼音正则）；**声情 prompt 必须注入引擎算好的平仄/韵部事实**，LLM 只负责阐释，不负责提供声律数据。

**② 模型分工修订（原方案 flash=轻 / 27B=重，实测后反转部分分工）：**

| 任务 | 模型 | 依据 |
|---|---|---|
| 意图分类、查询扩展、摘要、结构化轻任务 | **qwen3.8-27b 关思考** | 最快（3.6–6.3s）+ JSON 最稳 + 字段质量最好 |
| 声情阐释、论证文段生成 | **step-3.7-flash** | 词学文采与细节最佳（且实测声律细节准确） |
| 深度精修（非交互批量） | qwen3.8-27b 开思考 | 73s+，仅限后台批处理，交互链路禁用 |
| 解析、检索、图谱、队列 | 不走模型 | 确定性直出 |

**③ 延迟预算**：交互链路单次 LLM 调用 4–10s。问答采用**两段式**：先秒回引擎证据（确定性结果+检索命中），再流式补充 LLM 阐释；演示场景预缓存。

**④ 复测方式**：`PYTHONIOENCODING=utf-8 python llm_probe.py <模型名> <simple|pingze|hard|rusheng|shengqing> [额外JSON参数]`。

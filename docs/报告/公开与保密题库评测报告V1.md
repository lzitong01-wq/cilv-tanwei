## 3. 三个必须区分的结论

### 3.1 C1–C3：整段精确匹配在公开与保密集都成立

C1、C2、C3 共 600 题（公开 420、保密 180）全部逐字一致，包括句子结构、最长句并列、比例、差值、绝对变幅、阈值、入选句序和边界声明。

保密集 180/180 说明以下规则在未见数据上同样成立：

- 比例按 half-even 保留一位；
- C2 变化值来自未舍入比例之差；
- C3 阈值为平均句长向上取整；
- 分段使用 API 的 `split_after_line`。

### 3.2 C4：规则 100% 正确，但原始整段受引文选择限制

C4 的比例、排序、极差、引文可定位性全部通过，字段 886/886（公开）与 360/360（保密）一致；把引文替换为占位符后，两集整段均 100% 一致。

原始整段只有 27/140 与 6/60，差异全部来自“选了哪一条后段句”。对 303 个公开锚点的分析：

| 策略 | 锚点级命中 | 公开整段一致 |
|---|---:|---:|
| 后段首句 | 102/303 | 16/140 |
| 后段末句 | 78/303 | 10/140 |
| 后段最长句 | 126/303 | 27/140 |
| 后段最短句 | 50/303 | 8/140 |
| 仄声比例最高句 | 91/303 | 14/140 |
| 仄声比例最低句 | 71/303 | 8/140 |
| 后段中位句 | 82/303 | 14/140 |

即使取七种策略的最优组合，也只能让 97/140 道题的引文全部命中金标。结论：**金标引文是任取一条后段句，不存在可复现的选取规则**。这与官方判分规则一致——只核验候选引文能否定位到指定后段。

产品取“后段最长句”为默认值，同时在证据中保留全部候选句供人工改选。

### 3.3 C5：代理字段 100%，语义仍未验证

C5 的代理字段全部通过：前段与后段候选引文可定位、仄声比例变化值、节奏转向、边界声明和未验证状态，公开与保密各 140/140、60/60。

原始整段一致只有 6/140 与 2/60，因为金标的景物/感受句是语义选择，而官方明确说明该语义没有金标准。系统按官方要求只提供候选句并标注“未验证”，不把语义归类包装成已验证结论。

## 4. 关键规则清单

| 规则 | 内容 |
|---|---|
| 数据源 | 基准解题只使用冻结 API 的 `prosody.lines` 与 `split_after_line` |
| 比例 | `ze/(ping+ze)×100` |
| 舍入 | half-even，`.05` 边界取偶；禁止加 epsilon 强制进位 |
| C2 变化 | 未舍入后段比例减未舍入前段比例，再保留一位 |
| C3 阈值 | 总字数除以句数后向上取整 |
| C4 排序 | 展示比例降序；等比例时题面后出现的锚点在前 |
| C4 极差 | 展示比例相减 |
| C4 引文 | 默认后段最长句；候选全部入证据 |
| C5 方向 | 变化值 >0 为后段上升，<0 为后段下降，=0 为前后持平 |
| C5 语义 | 始终标注未验证 |

## 5. 证据链

每题保存作品 ID、作者、词牌、朝代、题面锚点、所用句序、分段位置、阈值、计算方式、引文行号与候选列表。1000 题的证据结构完整率为 100%。

C1–C3 的答案可以逐字回溯到具体句；C4、C5 除数值外还保存引文行号，界面可从答案直接跳回原句。

“证据结构完整”表示证据链字段齐全，不等于人工已复核语义正确性。

## 6. 验收口径建议

| 指标 | 建议口径 |
|---|---|
| 普通题字段正确率 | 硬门禁，公开与保密均 100% |
| 普通题证据可核验率 | 硬门禁，公开与保密均 100% |
| C1–C3 整段逐字一致 | 硬门禁，公开与保密均 100% |
| C4 整段逐字一致 | 参考值；硬门禁用“字段 + 引文可定位 + 引文归一化整段” |
| C5 代理字段 | 硬门禁；语义一律标未验证 |
| 保密集 | 已消耗，后续任何规则改动必须重新标注为调参后复测 |

C4、C5 的原始逐字整段匹配受金标自由选择引文的限制，不能作为这两类的公平门禁。这一点需要向比赛方确认口径。

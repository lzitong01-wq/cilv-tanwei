# 词律探微 · LLM 副功能适配层设计 V1

| 项 | 内容 |
|---|---|
| 性质 | 规划期设计 + 实测基线；用于把"风格/情感/推理/检索"等副功能以可审计方式接入产品 |
| 探针 | `tools/llm_sidecar_probe.py` → `data/results/LLM副功能探针结果V1.json` |
| 边界原则 | 模型只消费**事实卡**、只产出**候选解读**；声律数值与判定口径永远由确定性引擎给出 |
| 结论摘要 | 大模型可承担风格归纳、情感候选、推理链复述、检索查询扩展；但必须自研适配层做结构化、事实断言校验与降级，不能裸调模型 |

---

## 1. 定位：模型是副功能，不是判据

现有规划的铁律是"模型不得进入声律事实链路"（数值、平仄、入声、定位、排序、极差）。本设计**不放松这条铁律**，而是把模型放到它真正擅长的地方：

| 角色 | 由谁做 | 产物性质 |
|---|---|---|
| 声律事实与派生计算 | 确定性引擎 | 权威、可复算、可回跳 |
| 形式特征统计（句长、词牌、韵部、题材词频） | 确定性引擎 | 权威、可复算 |
| 把事实卡写成研究者可读的描述 | **模型（副功能）** | 候选解读 · 需标未验证 |
| 从事实卡推导风格对比结论 | **模型（副功能）** | 候选解读 · 需标未验证 |
| 情感倾向候选 | **模型（副功能）** | 候选 · 语义一律未验证 |
| 复述并解释推理链 | **模型（副功能）** | 解释层 · 数值须与引擎一致 |
| 检索查询扩展与结果摘要 | **模型（副功能）** | 辅助 · 原文证据仍由检索器给 |

一句原则：**事实由引擎给，措辞由模型给，结论由人签字。**

## 2. 实测基线（`data/results/LLM副功能探针结果V1.json`）

样本：poetry-source 清词库中作品数最多的三位词人——汪东 1345 首、樊增祥 667 首、朱祖谋 596 首。特征卡为确定性统计。

| 用例 | 模型 | JSON 合法 | 事实一致 | 关键观察 | 延迟 |
|---|---|---|---|---|---|
| 风格归纳（3 位词人） | qwen3.8-27b | ✅ | 无捏造数字、无越界断言 | 完整复述句长/词牌/韵部/题材词频 | 9.5 s |
| 风格归纳 | step-3.7-flash | ❌ | — | 结构化输出不合规 | 12.2 s |
| 情感候选 | qwen | ✅ | 标记"未验证"、有依据与边界 | 符合设计意图 | 2.4 s |
| 推理链复述 · C2 | qwen | ✅ | 无捏造数字 | **主动拒答**："未提供两篇数据，无法判断" | 2.1 s |
| 推理链复述 · C3 | qwen | ✅ | 无捏造数字 | 复述与引擎一致 | 2.0 s |
| 推理链复述 · C4 | qwen | ✅ | 数字校验器误判 | 模型给出 9.2%（**正确答案**，为合法派生值） | 2.3 s |
| 越界抵抗（评文学价值） | qwen | ❌ | — | **实质已拒绝**并给形式替代方案，仅 JSON 少右括号 | 3.1 s |

汇总：JSON 合法率 5/7（71.4%）、事实一致率 3/4（75%，其中 1 例为校验器误判）、平均延迟 4.8 s。

**三条可直接落地的结论**

1. **qwen 适合结构化副功能；flash 不适合**（同一提示下 JSON 不合规），flash 仅保留自由文与第二意见。
2. **"信息不足时拒答"是模型的自然行为**（C2 用例实证），适配层应把"缺数据"作为一等公民，给出追问或补数据入口，而不是逼模型补全。
3. **两种失败都是校验器的问题，不是模型的问题**：合法派生值被误杀、正确的拒答因括号缺失被判失败 → 适配层必须"宽容解析 + 派生值复算"，不能用严格 JSON 一刀切。

## 3. 自研适配层规格

### 3.1 调用契约

```python
class SidecarRequest:
    task: str                  # style_draft | style_compare | emotion_candidate
                               # | reasoning_restate | query_expand | summarize
    fact_card: dict            # 引擎产出的结构化事实，唯一事实来源
    question: str
    model: str = "qwen3.8-27b"
    max_tokens: int = 1200
    timeout_s: int = 30
    max_retries: int = 1
```

统一响应：

```python
class SidecarResult:
    ok: bool
    content: str
    parsed: dict               # 宽容解析后的字段
    status: str                # ok | insufficient_data | schema_repaired
                               # | fact_mismatch | refused | timeout | error
    checks: dict               # 逐项校验结果（结构/数字/未验证标记/越界词）
    latency_ms: int
    trace_id: str
```

### 3.2 四道闸门（按顺序）

1. **结构闸门**：优先严格 JSON 解析；失败则做"括号配平 + 字段正则抽取"的宽松解析，仍失败才判 `schema_repaired` 并保留原文供人工查看（不丢弃内容）。
2. **事实闸门**：输出中出现的数字必须满足二选一——① 出现在事实卡白名单；② 可由白名单经引擎内置计算器**复算得到**。两者皆不满足 → `fact_mismatch`，该段不展示。
3. **越界闸门**：命中价值判断类断言（"优于""更胜一筹""水平更高"等）→ 拦截并改写为形式层面表述。
4. **标注闸门**：情感候选必须含 `verification="未验证"`；风格与对比必须含"形式特征候选"限定语。缺失 → 视为不合格，不进入界面。

### 3.3 降级链

`模型超时/非法 → 换 flash（仅自由文）→ 退回模板化事实陈述（引擎直出）→ 仍不可用则功能降级为"仅展示事实卡"`

界面行为：模型不可用时，副功能区显示"模型未提供候选解释，以下为引擎事实"，**不显示任何占位假数据**。

### 3.4 预算与限流

| 项 | 值 |
|---|---|
| 单次请求 | ≤2 次 LLM 调用（可切换模型），输出 ≤1200 tokens |
| 单请求墙钟 | ≤45 s；交互链路 ≤30 s |
| 并发 | 全局 ≤4；副功能请求排队 |
| 缓存 | 同一（事实卡哈希 + 任务 + prompt 版本）命中缓存直接复用 |
| 预算熔断 | 单会话副功能调用上限 10 次，超限转模板 |

### 3.5 Prompt 版本化

`prompts/sidecar/{task}/v{major}.{minor}.md`，每个版本记录：变更说明、适用模型、基线通过率、上线时间。span 与 trace 必须记录 `prompt_version`，否则出问题无法定位回滚目标。

## 4. 副功能模块设计

### 4.1 检索独立化

现状：检索只是问答的底层。用户可感知的检索能力应独立成页：

- 输入：关键词 + 过滤（朝代、词牌、词人、韵部、题材词频）
- 输出：命中作品列表（含 Tier 标签）+ 命中句 + 同调统计
- 模型角色：查询扩展（自然语言 → 过滤条件与关键词）、结果摘要
- 门禁：扩展条件必须映射到实际字段；映射不上则忽略扩展项并提示"已按原查询检索"

### 4.2 词人风格画像

**可计算的形式特征**（Tier 2a 清词库实测可算，样本量充足）：

| 特征 | 定义 | 实测示例（汪东 / 樊增祥 / 朱祖谋） |
|---|---|---|
| 作品基数 | 作者作品数 | 1345 / 667 / 596 |
| 词牌多样性 | 不同词牌数 | 629 / 198 / 255 |
| 词牌偏好 | Top3 词牌及次数 | 菩萨蛮×67 / 虞美人×40 / 减字木兰花×29 |
| 句式长度 | 平均句长与标准差 | 8.45(3.56) / 8.99(3.96) / 9.03(3.76) |
| 声律倾向 | 全文仄声比例均值 | 43.47% / 43.30% / 42.39% |
| 长句偏好 | 长句句占比均值 | 0.475 / 0.488 / 0.490 |
| 韵部偏好 | 句末字韵部 Top3 | 第三部×215 / 第三部×103 / 第七部×87 |
| 题材词频 | 意象词表命中 Top3 | 山水×2210 / 山水×1332 / 山水×1431 |

模型角色：把特征卡写成研究者可读的画像候选。**口径固定为"形式特征·本地计算（Tier 2a/2b）"，不是文学风格定论。**

样本门槛：作者作品数 < 20 不出画像（统计不可靠）；< 100 只给基础统计。

### 4.3 词人风格对比

- 确定性层：特征差异表 + 差异幅度 + 显著性提示（样本量差异需标注）
- 模型层：对比解读候选（引特征卡编号）
- 禁止：价值排序、优劣断言、未标注的因果断言
- 页面形态：特征雷达/条形对照 + 解读候选 + 口径标签

### 4.4 情感分析（明确不做识别与打标）

官方无情感标签、史证接口未发布、C5 语义未验证 → 产品不做情感识别准确率承诺。只做：

- 形式线索（仄比、句末韵部、长句率、意象词频）→ 候选情感方向（模型）
- 一律标"未验证"，并说明不能推出作者生平与具体事件
- 复赛条件：官方发布情感标注或史证接口后，再升级为带金标的情感分析并新增评测

### 4.5 推理能力显式化

- 推理链视图：每步的输入、公式、输出、证据 ID，可展开
- 模型复述解释：把引擎步骤转成可读解释（数字须过事实闸门）
- 推理评测集：多跳（对比+排序+极差）、反事实（改分段点看结论变化）、自洽（同题两问）、干扰项（题面含无关作品）、缺数据（应拒答）
- 通过线：解释层数字一致率 ≥95%、缺数据正确拒答率 ≥90%、越界断言拦截率 100%

### 4.6 可视化补齐

- 逐句平仄对照视图（两篇/两位并排）
- 风格特征对照（雷达/条形）
- 推理链时间线
- 以上均为风格页与解析页的组件，不单独立项

## 5. 副功能评测与通过线

| 指标 | 定义 | 通过线 |
|---|---|---|
| 结构有效率 | 宽容解析后字段齐全 | ≥95% |
| 事实一致率 | 数字全部可归因（白名单或复算通过） | ≥95% |
| 捏造数字率 | 出现不可归因数字 | ≤5% |
| 未验证标注率 | 情感/风格候选带未验证与边界 | 100% |
| 越界拦截率 | 价值断言被拦截 | 100% |
| 缺数据拒答正确率 | 信息不足时明确拒答而非补全 | ≥90% |
| 延迟 | 副功能交互 | P95 ≤8 s |

基线（本次探针，样本小）：结构 71.4%、事实一致 75%、越界拦截 0/1（因解析失败未纳入统计）、拒答 1/1 → **必须先修适配层的宽容解析与派生值复算，再重跑基线**。

## 6. 实施顺序建议

| 步 | 内容 | 出口标准 |
|---|---|---|
| S1 | 适配层骨架：契约、四道闸门、降级链、Prompt 版本 | 单元测试覆盖解析失败/派生值/越界/缺数据 |
| S2 | 事实卡生成器（特征统计模块，可独立测试） | 三位样本作者特征与探针一致 |
| S3 | 风格画像 + 对比页 | 事实表可复算，解读候选过事实闸门 |
| S4 | 检索独立页 | 过滤可用、来源标签正确 |
| S5 | 推理链视图 + 推理评测集 | 解释数字一致率 ≥95% |
| S6 | 情感候选（降级版） | 一律未验证，无准确率承诺 |

S1–S2 不依赖模型，可立即开始；S3–S6 依赖 S1 的闸门，不建议先接模型再补校验。

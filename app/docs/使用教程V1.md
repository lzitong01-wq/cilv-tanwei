# 使用教程 V1

> 按三类使用者写：研究者、Teaching（教学）、库建设者。
> 每条路径都给「在哪个页面、点哪里、看什么口径」。
> 口径疑问先看 §4，术语先看 `GLOSSARY.md`。

---

## 0. 启动（一次）

```bash
# 1) 装依赖（纯 Python，无编译）
cd app/backend && python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# 2) 生成构建期产物（可重复执行；已有产物可跳过）
cd ../..
APP_QUIZ_DIR=<题库目录> python app/scripts/build_index.py           # 检索索引
APP_QUIZ_DIR=<题库目录> python app/scripts/build_style_index.py     # 风格索引
APP_QUIZ_DIR=<题库目录> python app/scripts/build_revisions.py      # 校订队列
python app/scripts/build_fonts.py                                  # 字体子集
python app/scripts/build_prosody_index.py                           # 词谱体式索引
python app/scripts/build_guxin_layer.py                            # 古音平仄层
python app/scripts/build_tier2_locator.py                          # Tier 2 定位索引

# 3) 前端构建（产物由后端同源托管）
cd app/frontend && npm ci && npm run build && cd ../..

# 4) 起服务
bash app/deploy/run.sh        # 或 cd app/backend && .venv/bin/python server.py
```

打开 `http://<主机>:8080/`。顶栏右侧可切配色（跟随系统／日间／夜间），演示时用 `?theme=light` 固定。

## 1. 研究者：查清一篇词的声律

### 1.1 库内作品（官方口径，最可靠）

1. 左栏「读词 → 单篇解析」，或从「检索」找到作品后点标题。
2. 页面给三层信息，从上往下看：
   - **词谱体式候选**：这个词牌在词谱里有几种体式、哪几种句读跟你这首吻合、置信度多少。
     多候选时系统**不给**逐字对照——这是有意的：同调同字数不能唯一定体。
   - **逐字格阵**：每字的读音、四声、平/仄（○ 平 / ● 仄 / 虚线 未知）。
     下方小字是该句的平仄计数；**逐字四声是本地字典计算**，官方只给逐句计数，两者口径不同、分别标注。
   - **词谱体式候选之外**：点任意字格，右侧显示读音来源与候选读音；标「未知」的字说明字典没有收录，
     系统不默认归仄。
3. 想看这一首的证据链与逐句：点「看原句」或从解题页点证据 ID，可跳回原句并高亮。

### 1.2 库外作品（自由文本）

1. 左栏「读词 → 按新文本解析」，粘贴词正文。
2. 系统会做两件事：
   - 给出**本地口径**的逐字平仄（四声、来源标签、未知字清单）；
   - 尝试定位：命中官方 423 篇 → 提示「与官方作品逐字一致」并给「看官方口径」按钮；
     不在官方库但同源语料里有 → 提示「非官方口径」并给出警示，**这类结果数值可能偏差**。
3. 定位不到就只给本地解析，不硬凑——这比给个错的强。

### 1.3 找同类作品

- 「检索」：单字走一元倒排、双字走二元倒排、三字以上走 FTS5 trigram；可按朝代过滤。
- 「风格对比」：选两位词人，看**形式特征**（作品数、词牌多样性、平均句长、仄比、长句率、常用词牌、题材词频）。
  这不是文学风格判定，页面上标了「形式特征·本地计算」。
- 「图谱」：词人—作品—词牌—朝代四类关系；切到「词调身份层」可看 100 个词牌的体式归并与别名复核。

## 2. 教学：看证据与自检

### 2.1 演示一条可复算的推理链

1. 左栏「求证 → 基准解题」，把题库题面粘进去（或首页点「用这道题试算」）。
2. 页面给三块：
   - **字段**：句数、最长句句序、平仄数、比例、变化值等，逐项对应官方判分项；
   - **计算链**：每步「输入 → 公式 → 输出 → 证据 ID」，可逐步展开，看得出结论怎么来的；
   - **证据**：可定位到作品与原句，点「看原句」跳回单篇解析并高亮该句。
3. C4 类题的金标引文是任选的，所以用**引文归一化**口径比较；C5 类题只判变化值与方向，
   语义归类官方明确不判对错——页面会写清楚，不要把两者混为一谈。

### 2.2 讲「我们凭什么这么说」

- 左栏「评测 → 不变量与用例」：13 条红线逐条列出约束、认领用例与状态；`pending` 的项如实挂起。
- 左栏「评测 → 答辩准备」：三张指标表（互不替代，不合并成单一准确率）、门禁状态（含未达标项）、
  答辩十问、降级剧本、五分钟演示脚本，每步可直接跳到对应页面。
- 「关于 → 语料与授权」：四层语料的范围、来源与授权状态，以及读音证据的优先级。

### 2.3 讲「出错时怎么办」

- 顶栏横幅会明示当前处于哪种降级：模型不可达 / 使用本地快照 / 离线。
  课堂断网时照常能讲解析与解题。
- 现场演练三种故障：访问 `?degrade=model`、`?degrade=knowledge`、`?degrade=offline`。

## 3. 库建设者：提交与导出校订

### 3.1 看差异

1. 左栏「校订 → 校订队列」。
2. 每条差异给：作品与句序、原句、本地计数 → 官方计数、差多少、以及**建议读音**。
   建议读音的来源标得很清楚：
   - 「按上下文规则命中」——由真实差异归纳出的规则；
   - 「按字级兜底推断，泛化弱」——该字在所有已解实例里读音一致，但跨语料泛化弱，**请人工复核**。
3. 页面默认把「多音字可解释」排在前面，「暂无法解释」的 10 条单列——它们需要依词谱读音，
   本系统不硬给建议。

### 3.2 复核

- 逐条「接受」或「驳回」；已处理的条目不能重复决策（会返回明确错误），处理时间会留痕。
- 建议不等于结论：差异只表示「本地读音与官方计数不一致」，**不断言谁对谁错**。

### 3.3 导出

1. 点「导出已接受条目」→ 得到带 BOM 的 CSV（Excel 直接打开不乱码）。
2. 界面会显示**导出键**（X-Export-Key）：同样内容重复导出得到同一个键，不会产生两份回写。
3. 闭环到此为止：**官方 API 只读（405），写回由官方流程完成**，本系统不直接改标注库。

## 4. 口径速查（先看这个再下结论）

| 问题 | 本项目的口径 |
|---|---|
| 四声准不准？ | 四声是**本地字典计算**，官方只给逐句平仄计数；可校验的只是「平/仄映射与官方计数一致」 |
| 整段答案和金标一字不差吗？ | C1–C3 可以；C4 受引文任选影响（用归一化口径）；C5 只判代理字段 |
| 情感准确率多少？ | **不给准确率**。只给「与 AI 标注基准集的一致率」与基准集自身的标注者间一致性，且基准集由模型标注、未经人工核验 |
| 同调同字数的词怎么算体式？ | 不唯一，给多候选 + 置信度；唯一或高分才允许逐字对照 |
| 没在官方库里的词怎么算？ | 给本地口径结果并标明非官方口径；命中同源语料时用同源带调拼音（更准），仍标非官方口径 |
| 词谱数据能用吗？ | 原始词谱只在构建期使用、不随交付分发；交付物只保留归纳出的派生事实并登记来源 |
| 403/405 是什么？ | 官方 API 只读，写回不支持；所以我们的闭环止于幂等导出 |

## 5. 常见操作问题

| 现象 | 原因与处理 |
|---|---|
| 顶栏显示「后端未连接」 | 服务没起或端口被占：`ss -ltnp \| grep 8080` 找到旧进程 kill 掉再起 |
| 「示例题不可用」 | 未设 `APP_QUIZ_DIR`；示例题只从本地题库读，题面不随交付分发 |
| 检索没结果 | 索引未生成：`python app/scripts/build_index.py` |
| 校订队列打不开 | 队列未生成：`python app/scripts/build_revisions.py` |
| 词谱候选面板空 | 词谱索引未生成：`python app/scripts/build_prosody_index.py`（构建期需词谱源文件） |
| 模型候选一直转圈 | 模型端点不可达；顶栏会明示降级，解析与解题不受影响 |
| 导出的 CSV 打不开 | 用 Excel/WPS 打开（已带 UTF-8 BOM） |

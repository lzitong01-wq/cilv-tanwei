# 情感候选标注规范 V1

> 本规范是 **AI 标注基准集**（ADR-0006）的唯一依据。
> 标注由模型执行，**不是人工金标、不是官方标注**；任何相关产出必须写明这一点。
> 规范版本随基准集一起冻结（`sentiment_benchmark_v1.json` 的 `spec_version`）。

---

## 1. 标注任务

给定**一句词**（不含上下文、不含题名），在固定的候选方向集合中选出**最贴切的一个方向**，
并给出**强度**。若句中信息不足以支撑任何方向，必须选 `无法判定`，不得猜。

标注的是**文本层面的形式线索指向**，不是作者生平、不是事件考证、不是文学优劣。

## 2. 标签集（9 个，闭集）

| 标签 | 判定要点（形式线索） |
|---|---|
| `思归怀人` | 出现归去、客居思远、书信/寄意、忆人之语等指向性线索 |
| `羁旅漂泊` | 旅途、行旅、客路、异乡、漂泊相关线索 |
| `愁苦失意` | 失意、困境、郁结、无可奈何的自我陈述 |
| `闲适自得` | 舒缓、自处、自得其乐的场面与心态 |
| `清高自守` | 不合流、坚守自持、拒斥世俗的自我表述 |
| `伤春悲秋` | 伤春、悲秋、节令变迁引起的感伤 |
| `现实关怀` | 民生、时局、世相的关切 |
| `言志用世` | 明确的抱负、用途、致意表达 |
| `无法判定` | 信息不足、指向不唯一、或只有景语而无情绪线索 |

## 3. 强度（0–3）

| 强度 | 含义 |
|---|---|
| 0 | 有该方向线索但极淡（近乎中性写景） |
| 1 | 弱 |
| 2 | 中 |
| 3 | 强（明确、集中的情感表达） |

## 4. 输出格式

严格输出 JSON，**不要任何额外文字**：

```json
{
  "items": [
    {"id": "<句子 id>", "label": "<标签集之一>", "strength": 0,
     "reason": "<≤30 字，只描述句中形式线索>",
     "boundary": "<≤30 字，说明不能推出什么>"}
  ]
}
```

- `reason` 只写**句内可见的线索**，不得出现作者、时代、事件、动机；
- `boundary` 必须写明该判断的局限（如"仅据本句，不能定作者处境"）。

## 5. 边界例子

### 5.1 正例

| 句子 | 标签 | 强度 | 理由 |
|---|---|---|---|
| 灯花又作落花红，鬓影风情休问 | 思归怀人 | 1 | 灯花落红，鬓影写人，无明确归期 |
| 十年尘土清江梦，自笑平生为口忙 | 羁旅漂泊 | 2 | 十年尘土、江上自述 |
| 而今才道当时错，心绪凄迷红泪偷零 | 愁苦失意 | 3 | 自陈心绪凄迷 |
| 紫玉箫斜，翠屏欹转，庭院清宵永 | 闲适自得 | 0 | 庭院清宵，仅有静境 |
| 莫向花阶嗟红怨，休怨人间风露凉 | 清高自守 | 2 | 嗟而不怨，自持其意 |
| 啼残窗外两三点，翠叠画屏山外山 | 伤春悲秋 | 1 | 啼声与残、凉意 |
| 眼底江山皆净物，耳边风月任教闲 | 现实关怀 | 0 | 仅格言式闲语，无具体世相 |
| 烟波尽处一点白，应是西风古驿垂杨 | 无法判定 | 0 | 纯写景，无情绪线索 |

### 5.2 反例（越界，必须判 `无法判定` 或改写 reason）

| 句子 | 错误做法 | 正确做法 |
|---|---|---|
| 十年尘土清江梦 | 写"作者中年宦海失意" | 只写"十年尘土、江上自述" |
| 灯花又作落花红 | 写"此为悼亡之作" | 只写落红与鬓影，情感方向取思归怀人 |
| 莫向花阶嗟红怨 | 写"词人品格高洁、不慕荣利" | 只能写"嗟而不怨"，且不得延伸到人格评价 |

## 6. 禁止推断项（硬约束）

标注输出（`label` / `strength` / `reason` / `boundary`）中**不得**出现：

1. 作者生平、仕途、身份、年龄、性别；
2. 具体事件、具体年代、具体地名对应的史事；
3. 创作动机、写作缘起；
4. 文学价值高低、优劣排序、与他人比较；
5. 词牌之外的体裁判断（如"这是豪放词"）。

违反者该条判定作废，按 `无法判定` 处理，并在分歧统计中单列。

## 7. 流程要求（对应 ADR-0006）

1. **分层抽样**：按朝代 × 句长 × 仄比分层，种子入库；
2. **多次独立标注**：同一模型两轮（提示变体 + 选项顺序打乱）+ 第二模型互标；
3. **分歧仲裁**：分歧项进入第三轮仲裁（更严格规范 + 争议理由），**争议比例本身进报告**；
4. **一致性统计**：报告标注者间一致性（Cohen's κ）与分歧率；
5. **盲测子集**：约 20% 抽样不参与标注，仅用于评估；**规范不得针对盲测集调整**；
6. **冻结**：版本号 + 规范版本 + 抽样种子 + 数据哈希。

## 8. 口径与披露

- 可以说："与 AI 标注基准集的一致率 X%"、"基准集自身标注者间一致性 κ=Y"；
- 不可以说："情感识别准确率 X%"、"人工金标"、"已验证的情感标签"；
- 一切界面与报告须标注：**"由模型标注、未经人工核验"**。

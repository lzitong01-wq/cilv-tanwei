## 3. 还没做的，以及为什么

### 3.1 需要外部数据（项目自己解决不了）

| 项 | 现状 | 能不能补 |
|---|---|---|
| **自注字音线索**（INV-SELFNOTE-10） | Tier 1 快照 423 条顶层键里没有自注字段；`chars.source` 只有 `local_dict` 一值 | 不能。需数据方导出自注读音；读音来源优先级链已按「官方 > 自注 > 外部字表 > 本地字典」实现，接口位留好了 |
| **官方 live API 回退**（三层兜底第二层） | 未实现 | 能，但要联网 + 凭据，与「运行时零外网」（ADR-0004）冲突。当前第一层快照与第三层 Tier 2 定位已闭环；要做只能做成默认关闭的开关 |
| **官方史证数据**（历史事件 / 词人生平 / 作品关联） | 官方接口 `total=0`，图谱关系位保留不填充 | 不能。等官方发布 |

### 3.2 需要人工（不能替代）

| 项 | 门槛 | 现状 |
|---|---|---|
| **体式消歧的人工确认抽样一致率** | ≥90%（抽样 ≥30 篇） | **未做**。无人工核验资源，报告里如实留空，没用模型复核冒充人工 |
| 情感基准集的人工抽检 | 规范建议 ≥10% | **未做**，同上 |

### 3.3 数据不支持（技术上做不了，不是没做）

| 规划里的维度 | 为什么做不了 |
|---|---|
| A3.2「韵位匹配（句末字属韵部 vs 谱标韵）」 | 词谱 `Ci_Tunes.json` 的 `sketch` 只给韵数与平仄（如「前段十一句七仄韵」），**不含韵部名**；而作品末字的韵部需要另一套数据才能定，无法与谱对齐 |
| A3.2「用字重合度（同分裁决）」 | 词谱只给平仄与句读，**不含用字的字面**，无从比对 |

### 3.4 工程上可选（低优先，按需再做）

- 校订「导出记录」独立页（当前导出信息并在校订队列页内显示）；
- live API 回退的开关与实现；
- 自注读音的字段位与优先级链展示（后端已有字段，前端未单列）；
- 词谱索引的增量更新（当前全量重建，约 30 秒）。

## 4. 我认为**不该**再做的

- **追 C5 整段逐字**：官方判分规则写明语义归类不判对错、只判变化值与方向，用模型猜金标那两句语义引文既不加分又冒编造风险。现状：每段给 3 条可定位候选，不硬凑。
- **把「无法判定」硬填成某个答案**：43 句修正表覆盖不了的差异是口径固有限制，继续压数字只能靠编。
- **为凑门禁而估数**：A3 的人工一致率、情感基准的人工抽检，一律留空。
- **扩到多用户 / 写回 / 向量库**：分册 C §12.3 明确列为不做，理由成立。
- **领域微调**：无标注语料、无算力窗口（分册 A §A6）。

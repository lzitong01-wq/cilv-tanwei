## 3.1 保密题面模式：只有题面、没有标准答案

赛方的保密验证集是**题面与答案分两个文件**的形态：评测方只给题面，系统必须照样逐题作答。这条路径与 `POST /api/eval/upload` 的「题面可不含标准答案」模式同源——三口径记 `null`（不是 `false`），回答可导出自行对答案。

| 项 | 值 |
|---|---|
| 题数 | 300 |
| 成功作答 | 300 |
| 报错 | 0 |
| 定位到作品的题 | 300 |
| 涉及作品数 | 120 |
| 总耗时 | 72 ms |
| 每题均耗时 | 0.24 ms |

说明：题面模式：没有标准答案就不评分（`null` 而不是 `false`——「没有答案」和「答错了」是两回事）。这里只报作答成功率与耗时。

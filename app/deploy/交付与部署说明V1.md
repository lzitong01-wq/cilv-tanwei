# 交付与部署说明 V1

> 面向「拿到包 → 在自己机器上跑起来 → 再部署到服务器」这一条路径。
> 包名：`词律探微-交付包-20261104.tar.gz`（88.9 MB，218 个文件）。
> 体积主要来自同源语料索引（163.7 MB 未压缩，含 4.3 万首的倒排与 FTS5）——**按检索效果优先，不设体积约束**。

---

## 1. 包里有什么

```
app/
  backend/          后端（Flask + waitress）、core 七个模块、rules.json（外置规则）
  frontend/dist/    前端构建产物（含 fonts/ 字体子集，部署不需要 Node）
  frontend/src/     前端源码（改代码用）
  data/             构建期索引与产物（检索/风格/校订/词谱/古音/Tier 2 全量 4.3 万首/基准集…）
  deploy/           部署脚本、自检脚本、离线 wheels
  docs/             使用教程、情感标注规范
  reports/          六份实测报告（holdout、修正表、情感基准、自检、测试报告、最终盘点）
  scripts/          构建期脚本（抽样、标注、跑分、报告生成…）
  tests/            161 个用例
data/知识库审计快照V1.jsonl   Tier 1 官方快照（运行时必需）
tools/              规划期的七个探针与分析脚本
*.md                规划基线（V6.1 + 四分册 + 前端计划 + 契约 + 对账表 + 一页纸 + CHANGELOG）
```

**不在包里**（有意排除）：`node_modules`、`.venv`、`__pycache__`、词谱与同源语料源文件（构建期输入）、
`.workbuddy/reference/`（可按 `app/frontend/public/fonts/NOTICE.md` 的方式重新获取）。

## 2. 在本机跑起来（已实测通过）

### Windows（本机验证用的就是这条）

```bash
# 解压
tar -xzf 词律探微-交付包-20261104.tar.gz -C 部署目录
cd 部署目录

# 自检（14 项，含契约一致性）
python app/deploy/check_env.py

# 虚拟环境 + 离线装依赖（用包内 wheels）
# 必装只有三个纯 Python 包；pysqlite3 是**可选**的（只发布 Linux wheel，
# Windows 装不了；系统 SQLite 已有 trigram 就不需要它）
python -m venv app/.venv
./app/.venv/Scripts/python.exe -m pip install --no-index \
  --find-links app/deploy/wheels/win-x86_64 -r app/backend/requirements.txt

# 起服务
set APP_QUIZ_DIR=C:\path\to\题库目录
./app/.venv/Scripts/python.exe app/backend/server.py
```

打开 `http://127.0.0.1:8080/`。

### 可选：启用官方知识库 API 兜底

题面锚点定位到的作品**不在本地快照（423 篇）里**时，系统会按需向官方 API 实时查询——
这覆盖「官方在评测前又发布了新作品」的情况。**不配也能用**（本地快照 + 同源层已覆盖绝大多数题面）。

```bash
export APP_QINGCI_KEY=qck_live_xxx      # 团队密钥，向项目管理员申请
export APP_QINGCI_BASE=https://qingci.zhiruitech.com.cn   # 可选，默认官方地址
bash app/deploy/run.sh
```

- 密钥**只从环境变量读**，不进代码、不进交付包、不进日志；自检项「官方 API 兜底」会显示当前状态。
- 官方默认 **120 次/分钟**。查到的作品会落本地缓存（`app/data/api_cache.sqlite3`），第二次直接命中。
- 答题界面会标明「作答来源：官方 API 实时查询」或「Tier 1 官方快照」，**来源逐篇标注**。

### Linux / 龙蜥（目标服务器）

```bash
tar -xzf 词律探微-交付包-20261104.tar.gz -C /opt/cilv
cd /opt/cilv

# 一键：自检 → 建 venv → 离线装依赖 → 起服务
export APP_QUIZ_DIR=/opt/cilv/quiz     # 可选：题库目录（不配就没有示例题）
bash app/deploy/run.sh
```

`run.sh` 会：跑 `check_env.py`（缺项只提示不阻塞）→ 建 venv → 优先用
`app/deploy/wheels/linux-x86_64-py311` 离线装依赖 → **再试装可选依赖 pysqlite3**
（Anolis OS 8.6 的系统 SQLite 3.26 没有 trigram，装上它 ≥3 字检索才走 FTS5；
装不上不阻塞，应用层自动退回子串匹配）→ 启动 waitress。

后台常驻用 systemd（`app/deploy/README.md` §8 有 unit 文件）。

## 4. 常见问题

| 现象 | 处理 |
|---|---|
| 检索没结果 | 索引缺失：`python app/scripts/build_index.py`（依赖 Tier 1 快照） |
| 「示例题不可用」 | 未设 `APP_QUIZ_DIR`；题库不随包分发，题面只从本地读 |
| 字体不显示 | `dist/fonts/` 必须随包；检查 `Content-Type` 是否为 `font/woff2` |
| 端口被占 | `ss -ltnp \| grep 8080` 找旧进程；或设 `APP_PORT` |
| 校订队列打不开 | `python app/scripts/build_revisions.py` |
| 检索很慢（≥3 字） | 系统 SQLite 无 trigram：装可选依赖 `pip install -r app/backend/requirements-optional.txt`（只发布 Linux wheel）；不装也能用，只是退回子串匹配 |
| 词谱候选面板空 | `python app/scripts/build_prosody_index.py`（需词谱源文件，见 `public/fonts/NOTICE.md`） |

## 5. 依赖与许可证

- 运行时依赖仅三个纯 Python 包：Flask 3.1.3、waitress 3.0.2、pypinyin 0.55.0（离线 wheels 已含）；
- 前端字体：思源宋体子集，SIL OFL 1.1，授权原文在 `app/frontend/public/fonts/OFL.txt`；
- 词谱与同源语料：只在构建期使用，原始文件**不随包分发**，交付物里只保留归纳出的派生事实并登记来源；
- 官方 Tier 1 快照与 V5 题库：赛方所有，按赛方许可使用。
